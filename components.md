# Hardware Components

## Arduino Uno
Main microcontroller used in the documented prototype. It controls the connected sensors/modules and processes ultrasonic readings.

## Ultrasonic Sensor
Measures distance to the road surface. A change in the measured distance is used by the supplied implementation as the pothole-detection condition.

## GPS Module
Provides latitude and longitude information for the detected location.

## Motor Driver and Motors
The motor driver controls the DC motors, allowing the prototype vehicle/robot to move during testing.

## ESP8266 Wi-Fi Module
Listed in the hardware components of the supplied project documents for IoT/Wi-Fi communication.

## ESP32-CAM
The project material also describes an ESP32-CAM based image-capture and Telegram workflow.

## Buzzer
Provides a local audible alert when a pothole condition is detected.

## Other Components
Jumper wires, breadboard, power supply, and supporting hardware.
