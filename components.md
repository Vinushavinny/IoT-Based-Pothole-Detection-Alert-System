# Hardware Components

## Arduino Uno
Main microcontroller used in the prototype. It controls the connected sensors and modules and processes ultrasonic readings.

## Ultrasonic Sensor
Measures the distance to the road surface. Changes in the measured distance are used for pothole detection.

## GPS Module
Provides latitude and longitude information for the detected pothole location.

## Motor Driver and Motors
The motor driver controls the DC motors, allowing the prototype vehicle/robot to move during testing.

## ESP8266 Wi-Fi Module
Used for Wi-Fi and IoT communication in the prototype.

## ESP32-CAM
Used for image capture and the Telegram-based alert workflow.

## Buzzer
Provides a local audible alert when a pothole is detected.

## Other Components
Jumper wires, breadboard, power supply, and other supporting hardware.
